# 告别两秒断音：Mac mini 有线上网，HomePod mini 无线播放

**网线继续上网，声音交给 Wi-Fi。**

如果 HomePod mini 在 iPhone 上播放正常，但 Mac mini 一选中它就无声、短暂播放后又切回内置扬声器，可以按这份指南检查双网卡下的 AirPlay 连接。

本指南提供一套经过实际案例验证的配置方法：让有线接口负责 IPv4 上网，让 Wi-Fi 保留 AirPlay 所需的本地 IPv6 通信，并通过路由区分互联网与 HomePod 流量。

## 适用情况

- Mac mini 同时连接网线和 Wi-Fi。
- HomePod mini 连接同一局域网的 Wi-Fi。
- iPhone 播放正常，Mac 只用 Wi-Fi 时也正常。
- Mac 接入有线网络后出现断音或自动切回内置扬声器。

## 完成后

- 普通互联网 IPv4 流量走网线。
- 发往 HomePod 的指定 IPv4 流量走 Wi-Fi。
- 有线接口关闭 IPv6，Wi-Fi 的 IPv6 设为“仅本地链接”。
- 可选开机恢复一次路由，执行完退出，不持续轮询。
- 提供验证步骤与撤销方法。

## 开始操作

阅读 [操作指南](操作指南.md)，依次完成参数确认、设置备份、临时验证和可选的开机恢复。

该方法针对特定的双接口通信问题，不保证适用于所有 AirPlay 故障。关闭公网 IPv6 会影响仅支持 IPv6 的目标；路由检查通过后，还需实际试听确认。
